# Python Flow Lab

Учебный визуализатор базового Python для учеников 12–14 лет. Код редактируется слева, а справа заранее формируется стабильный граф нод. Во время выполнения по графу анимируются runtime-данные.

## Возможности

- пошаговое выполнение и автоматический запуск;
- быстрый прогон до выбранной строки с сохранением корректного состояния;
- стабильные ноды кода, сформированные до запуска;
- runtime-значения, история ноды и снимки переменных;
- анимация движения данных от последнего места записи переменной;
- `if/else`, `while`, `for`, `range()`;
- переменные, арифметика, списки/словари, индексы;
- функции, аргументы, значения по умолчанию и `return`;
- `print()` в встроенной консоли;
- `input()` через встроенное поле ввода, без `window.prompt()`;
- ограничение количества шагов для защиты от очевидных бесконечных циклов.

## Архитектура

1. **Ace Editor** — редактирование Python.
2. **Pyodide 314.0.6** — CPython в браузере. Пользовательский код через `eval/exec` не запускается: Python `ast` используется только для синтаксического разбора.
3. **engine.py** — превращает AST в компактное JSON-представление поддерживаемого учебного подмножества Python.
4. **MiniPythonRuntime (app.js)** — генераторный интерпретатор. Каждая исполняемая инструкция создаёт событие `line`, `data`, `decision`, `call`, `output` или `input`.
5. **DOM + SVG** — стабильные ноды, рёбра потока и анимированные runtime-токены.

Такой подход выбран специально ради настоящего `Step`, визуального входа в функции и асинхронного браузерного `input()`.

## Запуск локально

Из каталога проекта:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Открывать `index.html` двойным кликом через `file://` не рекомендуется: браузер может запретить загрузку `engine.py`.

## Учебное подмножество

Поддерживается: `Assign`, `AugAssign`, `if/else`, `while`, `for`, `def`, позиционные аргументы, простые default-аргументы, `return`, `break`, `continue`, `pass`, `print`, `input`, `range`, `len`, `int`, `float`, `str`, `bool`, `min`, `max`, `abs`, `round`, `list`, `.append()`, `.pop()`, `.upper()`, `.lower()`.

Намеренно не поддерживается: `import`, классы, исключения, comprehensions, генераторы, файлы, async/await и сторонние библиотеки.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` автоматически публикует корень репозитория после push в `main`. В **Settings → Pages** выберите источник **GitHub Actions**.

Также добавлены ручные скрипты запуска деплоя:

- `deploy-github-pages.ps1` для Windows PowerShell;
- `deploy-github-pages.sh` для Bash.

Скрипт проверяет чистоту git-дерева и выполняет push текущего `main`; этот push запускает Pages workflow.

## Ограничения

Это не полный Python-дебаггер и не замена CPython. Цель проекта — наглядно показать первые темы программирования, поэтому сложный синтаксис должен явно отклоняться парсером, а не выполняться частично и непредсказуемо.
