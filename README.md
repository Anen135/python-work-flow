# Python Flow Lab

Учебный визуализатор базового Python для учеников 12–14 лет. Код редактируется слева, а справа заранее формируется стабильный граф нод. Во время выполнения по графу анимируются runtime-данные.

## Возможности

- поиск нод по коду, области видимости и номеру строки;
- масштабирование, обзор перетаскиванием фона, переход к текущему шагу;
- выделение нескольких нод через Shift + клик, групповое перемещение и привязка к сетке;
- выравнивание по краям и центрам, равные интервалы, автоматическая раскладка по запросу;
- по умолчанию ноды идут слева направо с промежутком 160 px; кнопка «Авто» восстанавливает эту раскладку;
- линии соединяют центры боковых портов, включая порты ветвлений и runtime-данных;
- `return` получает значения для выражения слева и передаёт результат через правый порт `Return` к ноде вызова; цвет связи соответствует типу результата;
- отмена и повтор до 60 изменений расположения;
- автосохранение кода и раскладки в браузере, открытие и скачивание `.py`;
- пошаговое выполнение и автоматический запуск;
- быстрый прогон до выбранной строки с сохранением корректного состояния;
- стабильные ноды кода, сформированные до запуска;
- runtime-значения, история ноды и снимки переменных;
- анимация движения данных от последнего места записи переменной;
- `if/else`, `while`, `for`, `range()`;
- переменные, арифметика, списки/словари, индексы;
- функции, аргументы, значения по умолчанию и `return`;
- `print()` в встроенной консоли;
- `input()` через встроенное поле ввода, без `window.prompt()`;
- ограничение количества шагов для защиты от очевидных бесконечных циклов.

## Архитектура

1. **Ace Editor** — редактирование Python.
2. **Pyodide 314.0.6** — CPython в браузере. Пользовательский код через `eval/exec` не запускается: Python `ast` используется только для синтаксического разбора.
3. **engine.py** — превращает AST в компактное JSON-представление поддерживаемого учебного подмножества Python.
4. **MiniPythonRuntime (app.js)** — генераторный интерпретатор. Каждая исполняемая инструкция создаёт событие `line`, `data`, `decision`, `call`, `output` или `input`.
5. **DOM + SVG** — стабильные ноды, рёбра потока и анимированные runtime-токены.

Такой подход выбран специально ради настоящего `Step`, визуального входа в функции и асинхронного браузерного `input()`.

## Запуск локально

Из каталога проекта:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Открывать `index.html` двойным кликом через `file://` не рекомендуется: браузер может запретить загрузку `engine.py`.

## Учебное подмножество

Поддерживается: `Assign`, `AugAssign`, `if/else`, `while`, `for`, `def`, позиционные аргументы, простые default-аргументы, `return`, `break`, `continue`, `pass`, `print`, `input`, `range`, `len`, `int`, `float`, `str`, `bool`, `min`, `max`, `abs`, `round`, `list`, `.append()`, `.pop()`, `.upper()`, `.lower()`.

Намеренно не поддерживается: `import`, классы, исключения, comprehensions, генераторы, файлы, async/await и сторонние библиотеки.

## GitHub Pages

Перед публикацией выполняются проверки JavaScript и браузерные сценарии, включая привязку линий к портам при разных масштабах. В Pages отправляются только файлы приложения; зависимости разработки и тестовые артефакты в сайт не попадают.

Workflow `.github/workflows/deploy-pages.yml` автоматически публикует корень репозитория после push в `main`. В **Settings → Pages** выберите источник **GitHub Actions**.

Также добавлены ручные скрипты запуска деплоя:

- `deploy-github-pages.ps1` для Windows PowerShell;
- `deploy-github-pages.sh` для Bash.

Скрипт проверяет чистоту git-дерева и выполняет push текущего `main`; этот push запускает Pages workflow.

## Ограничения

Это учебный интерпретатор ограниченного подмножества Python, а не полный Python-отладчик. Неподдерживаемый синтаксис должен явно отклоняться парсером.

Сохранение привязано к браузеру и адресу сайта. Для переноса проекта скачайте `.py` (раскладка в Python-файл не входит). При изменении кода история перемещений очищается. Ace и Pyodide загружаются с CDN, поэтому для первого открытия нужен интернет.

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Запуск / пауза | Ctrl + Enter |
| Шаг / сброс | F10 / Shift + F10 |
| Скачать код | Ctrl + S |
| Поиск ноды | Ctrl + K |
| Предыдущая / следующая нода | Alt + ↑ / ↓ |
| Вместить / масштаб 100% | F / 0 на графе |
| Выделить все | Ctrl + A на графе |
| Отменить / повторить раскладку | Ctrl + Z / Ctrl + Shift + Z на графе |
| Переместить выделение | Стрелки, Shift — увеличенный шаг |
| Очистить выделение и закрыть инспектор | Escape |

На macOS вместо Ctrl используется ⌘. Сочетания редактирования в Ace продолжают работать независимо от графа. Масштаб у курсора — Ctrl/⌘ + колесо.

## Проверки разработки

```bash
npm ci
npx playwright install chromium
npm run check
npm test
# Дополнительно: реальная загрузка CDN и WebAssembly (нужен интернет)
npm run test:live
```

Нужен Python 3.14 и Node.js 22+. В Windows тесты используют установленный Microsoft Edge, в Linux — Chromium Playwright. Тесты используют настоящий Ace, DOM/SVG и интерпретатор JavaScript; ответы AST заранее вычисляются локальным `engine.py`. Загрузка Pyodide с CDN подменяется, поэтому эти тесты не проверяют доступность CDN и запуск WebAssembly. Сценарии покрывают поиск, мобильную ширину, групповое выравнивание, отмену/повтор, сохранение после перезагрузки, перемещение при масштабе, выполнение циклов, input(), ошибку синтаксиса, импорт и экспорт.
